# DoAndroidsTrain

This small demo shows a Tron-style orientation tracker with optional map overlay.

## Google Maps Static API

If you would like to load an additional static map texture, supply a Google Maps
API key via the `googleKey` query parameter:

```
index.html?googleKey=YOUR_KEY_HERE
```

You may also set `window.GOOGLE_MAPS_API_KEY` before loading the scripts.
